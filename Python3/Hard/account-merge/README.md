<h2><a href="https://www.geeksforgeeks.org/problems/account-merge/1">Account Merge</a></h2><h3>Hard</h3><hr><p><span style="font-size: 18px;">Given a 2D array <strong>arr[][]</strong>&nbsp;of size <strong>n</strong>, where each element arr[i] is an array of strings representing an account, where the first element arr[i][0] is a name, and the rest of the elements are emails associated with this name. Two accounts belong to the same person if there is a common email associated with both accounts. A person can have any number of accounts initially, but all have the same name.</span></p>
<p><span style="font-size: 18px;">Merge these accounts and return them in the following format: the first element of each account is the name, and the rest of the elements are emails<strong> </strong>in<strong> </strong>lexicographically<strong> </strong>sorted order.</span></p>
<p><span style="font-size: 18px;"><strong>Note:</strong> Accounts themselves can be returned in any order. Even if two accounts have the same name, they may belong to different people as different people could have the same name.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre style="background: #eeeeee; border: 1px solid #cccccc; padding: 5px 10px; --darkreader-inline-bgimage: initial; --darkreader-inline-bgcolor: #222426; --darkreader-inline-border-top: #3e4446; --darkreader-inline-border-right: #3e4446; --darkreader-inline-border-bottom: #3e4446; --darkreader-inline-border-left: #3e4446;"><span style="font-size: 18px;"><strong style="font-size: 18px;">Input: </strong><span style="font-size: 18px;">n = 4,<br>arr[][] =<br>[["John", "johnsmith@mail.com", "john_newyork@mail.com"],<br>["John", "johnsmith@mail.com", "john00@mail.com"],<br>["Mary", "mary@mail.com"],<br>["John", "johnnybravo@mail.com"]]<br></span><strong style="font-size: 18px;">Output:</strong><span style="font-size: 18px;"><br>[["John", "john00@mail.com", "john_newyork@mail.com", "johnsmith@mail.com"],<br>["Mary", "mary@mail.com"],<br>["John", "johnnybravo@mail.com"]]<br></span><strong style="font-size: 18px;">Explanation:</strong><span style="font-size: 18px;"><br>There are three accounts with the same name "John", and two of them share a common email which is "johnsmith@mail.com", thus these two accounts are merged, and remaining two will remain unchanged.</span></span></pre>
<pre style="background: #eeeeee; border: 1px solid #cccccc; padding: 5px 10px; --darkreader-inline-bgimage: initial; --darkreader-inline-bgcolor: #222426; --darkreader-inline-border-top: #3e4446; --darkreader-inline-border-right: #3e4446; --darkreader-inline-border-bottom: #3e4446; --darkreader-inline-border-left: #3e4446;"><span style="font-size: 18px;"><strong style="font-size: 18px;">Input: </strong><span style="font-size: 18px;">n = 5,<br>arr[][] =<br>[["Gabe", "Gabe00@m.co", "Gabe3@m.co", "Gabe1@m.co"],<br>["Kevin", "Kevin3@m.co", "Kevin5@m.co", "Kevin0@m.co"],<br>["Ethan", "Ethan5@m.co", "Ethan4@m.co", "Ethan0@m.co"],<br>["Hanzo", "Hanzo3@m.co", "Hanzo1@m.co", "Hanzo0@m.co"],<br>["Fern", "Fern5@m.co", "Fern1@m.co", "Fern0@m.co"]]<br></span><strong style="font-size: 18px;">Output:</strong><span style="font-size: 18px;"><br>[["Ethan", "Ethan0@m.co", "Ethan4@m.co", "Ethan5@m.co"],<br>["Gabe", "Gabe0@m.co", "Gabe1@m.co", "Gabe3@m.co"],<br>["Hanzo", "Hanzo0@m.co", "Hanzo1@m.co", "Hanzo3@m.co"],<br>["Kevin", "Kevin0@m.co", "Kevin3@m.co", "Kevin5@m.co"],<br>["Fern", "Fern0@m.co", "Fern1@m.co", "Fern5@m.co"]]<br></span><strong style="font-size: 18px;">Explanation:</strong><span style="font-size: 18px;"><br>There is no common email in any of the users.</span></span></pre>
