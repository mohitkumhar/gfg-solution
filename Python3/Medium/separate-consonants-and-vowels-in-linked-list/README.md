<h2><a href="https://www.geeksforgeeks.org/problems/arrange-consonants-and-vowels/1">Separate Consonants and Vowels in Linked List</a></h2><h3>Medium</h3><hr><p><span style="font-size: 14pt;">Given a singly linked list containing nodes with English alphabets <strong>('a'-'z')</strong>. Rearrange the linked list&nbsp;in such a way that all the vowels come before the consonants while maintaining the order of their arrival.&nbsp;</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 12pt;"><span style="font-size: 14pt;"><strong>Input: </strong>head : a -&gt; b -&gt; c -&gt; e -&gt; d -&gt; o -&gt; x -&gt; i </span><br><span style="font-size: 14pt;"><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/927800/Web/Other/blobid0_1777959738.png" width="639" height="72"></span><br><span style="font-size: 14pt;"><strong>Output:</strong> a -&gt; e -&gt; o -&gt; i -&gt; b -&gt; c -&gt; d -&gt; x</span><br><span style="font-size: 14pt;"><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/927800/Web/Other/blobid1_1777959752.png" width="639" height="72"></span><br><span style="font-size: 14pt;"><strong>Explanation:</strong> After moving all vowel nodes ahead of consonant nodes (without changing their relative order), the resulting linked list is as shown in the output.</span></span></pre>
<p><span style="font-size: 14pt;"><strong>Constraints:</strong><br>1 ≤ size of linked list ≤ 10<sup>5</sup><br>'a' ≤ elements of linked list ≤ 'z'</span></p>
